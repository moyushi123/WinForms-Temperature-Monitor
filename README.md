# WinForms Temperature Monitor

基于 C#、.NET 8 和 WinForms 开发的设备温度监控上位机，用于练习工业设备通信、温度数据采集、实时监控和异常处理等功能。

## 项目介绍

本项目是一个面向工业监控场景的桌面应用程序，围绕设备温度采集与监控展开，采用模块化的代码结构，将界面、数据模型、通信基础设施和业务服务分开组织。

项目支持 Modbus RTU 和 Modbus TCP 通信模式的开发与验证，可结合设备模拟器进行功能测试。

## 主要功能

- **设备通信**：支持 Modbus RTU 串口通信和 Modbus TCP 网络通信。
- **温度采集**：读取设备寄存器数据，并根据约定的数据格式转换为温度值。
- **实时监控**：显示温度数据和设备通信状态。
- **数据可视化**：展示温度变化趋势（以实际完成的曲线功能为准）。
- **报警与日志**：根据设定的温度阈值进行报警判断，并记录运行过程中的相关信息（以实际实现为准）。
- **数据导出**：支持将采集数据导出为 CSV 文件。
- **配置管理**：使用 JSON 保存和读取相关配置。
- **异常处理**：针对通信超时、连接失败等情况进行处理，提升程序运行的稳定性。

## 运行环境

- Windows
- Visual Studio 2022 或其他支持 .NET 8 的开发环境
- .NET 8 SDK
- 可用的 NuGet 包源，用于还原项目依赖

如果使用 Modbus RTU，需要准备可用的串口、串口转接设备或虚拟串口对；如果使用 Modbus TCP，可以连接支持 Modbus TCP 的设备，或使用相应的模拟器进行测试。

## 如何运行

1. 克隆本仓库：

   ```bash
   git clone <你的 GitHub 仓库地址>
   ```

2. 使用 Visual Studio 打开 `ModbusMonitor.csproj`，或打开对应的解决方案文件（如果仓库中包含 `.sln`）。

3. 还原 NuGet 依赖。

4. 根据所选通信模式，配置串口参数，或配置设备 IP 地址和 TCP 端口。

5. 如果使用独立的设备模拟器，先启动模拟器，并确认通信参数与上位机配置一致。

6. 启动项目，进行设备连接和温度采集测试。

## 通信与数据处理说明

### Modbus RTU

通过串口与设备进行通信，需要正确配置串口号、波特率、校验位、数据位和停止位。寄存器地址、功能码及数据缩放规则应根据实际设备的通信协议文档确定。

### Modbus TCP

通过 TCP/IP 与设备通信，需要配置正确的 IP 地址和端口。使用模拟器测试时，客户端和模拟器应采用匹配的网络配置。

### 温度数据解析

设备寄存器通常以 16 位整数等形式返回数据。程序需要根据设备协议解析寄存器值，并按照实际约定进行缩放，例如原始值 `285` 在采用 0.1 ℃ 缩放规则时表示 `28.5 ℃`。
