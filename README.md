# WinFormsTemperatureMonitor

基于 C#、.NET 8 和 WinForms 的 Modbus 温度监控学习项目，支持 Modbus RTU / TCP 通信、温度采集、实时曲线、参数写入及文件记录。通过软件模拟设备进行通信测试，无需真实硬件即可演示。

## 功能

- 支持切换 Modbus RTU 和 Modbus TCP 通信方式。
- 定时读取输入寄存器，显示当前温度与有效采样次数。
- 根据设置的报警阈值显示温度正常或超限状态。
- 写入保持寄存器中的目标温度，并读回比较验证。
- 使用 ScottPlot 绘制最近 100 条有效采样的温度曲线。
- 按日期追加保存 CSV 采样数据和文本运行日志。
- 通过参数设置窗口配置通信参数、寄存器地址、采集间隔、超时和报警阈值，使用 JSON 保存配置。
- 使用后台任务执行同步通信，避免等待设备响应时阻塞界面。
- 通信忙碌时跳过新的采集请求，处理超时、连接失败及文件保存失败。

## 开发运行

1. 在 Windows 上安装支持 .NET 8 的 Visual Studio，并安装“.NET 桌面开发”工作负载。
2. 下载或克隆本仓库，使用 Visual Studio 打开项目中的 `.csproj` 文件（原项目名为 `ModbusMonitor.csproj`）。
3. 等待 NuGet 依赖还原完成。
4. 启动兼容的 Modbus 模拟设备，并确认其通信参数和寄存器映射。
5. 运行上位机，选择通信方式，检查参数设置，点击“开始监控”。

仓库名称与 `.csproj` 文件名称可以不同，打开时以仓库内实际项目文件为准。

### Modbus TCP 测试

启动配套练习中的 TCP 模拟设备程序，使其监听 `127.0.0.1:1502`。模拟设备需要单独准备和启动，上位机不会自动启动它。

| 参数 | 默认值 |
| --- | --- |
| IP | `127.0.0.1` |
| 端口 | `1502` |
| 站号 / Unit ID | `1` |
| 温度输入寄存器地址 | `0` |
| 目标温度保持寄存器地址 | `0` |

`127.0.0.1` 指当前电脑；使用该地址测试时，上位机和模拟设备须运行在同一台电脑上。

### Modbus RTU 测试

使用虚拟串口工具建立一对互连端口，例如 `COM10 ↔ COM11`：

- 上位机打开 `COM10`，RTU 模拟设备打开 `COM11`。
- 双方设置为 `9600` 波特率、`Even` 校验、`8` 数据位、`1` 停止位。
- 模拟设备站号设为 `1`，并保持运行。

也可以连接真实设备，但必须按设备说明书设置串口参数和寄存器地址。

### 数据约定

本演示使用协议中的零基地址。输入寄存器 `0` 与保持寄存器 `0` 属于不同数据区。

- 输入寄存器 `0`：实际温度，原始值 `285` 表示 `28.5℃`。
- 保持寄存器 `0`：目标温度，写入 `375` 表示 `37.5℃`。
- 读取时除以 `10.0`，写入时按 10 倍换算。
- 温度倍率是模拟设备约定，不是 Modbus 协议固定规则。
- 修改目标温度不会自动改变模拟设备的实际温度；本项目不模拟温控系统的物理过程。

## 数据保存

通过界面中的“打开保存目录”查看文件，默认根目录为：

```text
%LOCALAPPDATA%\ModbusMonitor
```

采样文件位于 `Samples`，运行日志位于 `Logs`。CSV 按日期追加保存，包含采集时间、通信方式和温度。

曲线只保留最近 100 条采样，删除曲线缓存中的旧记录不会删除 CSV 历史数据。采集成功与保存成功分别统计：设备成功返回数据后，即使文件写入失败，仍算一次有效采样。

## 发布

在 `.csproj` 所在目录执行：

```powershell
dotnet publish .\ModbusMonitor.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -p:PublishTrimmed=false -o ..\WinFormsTemperatureMonitor_Release
```

如项目文件已改名，请同步修改命令中的文件名。发布完成后运行输出目录中的 EXE。交付时保留整个发布目录，包括依赖 DLL。

该发布方式自带 .NET 运行时，但不包含模拟设备程序或虚拟串口驱动；无真实设备时仍需单独启动模拟设备。

## 实现说明与范围

- 每次通信操作建立并释放连接，尚未实现长连接管理或复杂重连策略。
- 停止监控不强制取消已开始的读取；读取结束后不再显示本轮自动采集结果。
- 写入后读回不一致会报告失败；响应或读回失败时，设备最终值可能尚未确认。
- CSV 和日志采用简单同步文件写入，适用于当前低频学习演示；慢磁盘可能影响界面响应。
- 本项目基于教程与辅助指导完成，用于练习工业通信和桌面开发，尚未在真实生产现场验证。
